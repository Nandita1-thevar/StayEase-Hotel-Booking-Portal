# Hotel Booking Portal

Full-stack interview assignment starter scaffold.

## Stack
- Frontend: React + TypeScript + Vite
- Backend: Java 17+ / Spring Boot / Spring Data JPA
- Database: MySQL

## Project structure
- `frontend/` React application
- `backend/` Spring Boot REST API
- `database/` schema and sample data
- `screenshots/` screenshots or demo assets

## Setup status
This is a project scaffold with starter configuration and placeholder source files. The booking workflow, database entities, APIs, validation, concurrency handling, QR verification, and tests still need to be implemented.

## Run locally
See `frontend/README.md` and `backend/README.md` for setup instructions.

Do not commit real passwords, API keys, or other secrets. Configure local database credentials using environment variables or an untracked local properties file.
